# Original direction: signal / evidence

## Why this is different

The previous version borrowed Wande's rounded card grid too directly. This revision uses an open editorial canvas and treats the portfolio like a record of built systems: a direct opening, one large piece of evidence, then a concise work history. The visual signature is the project image reveal when the reader selects a different build. The animation describes a real change in focus.

## Palette

- Near black `#09090C` — default page background, continuous with the opening.
- Warm white `#F2EEEB` — headline and primary text.
- Dusty rose `#B7ABAD` — supporting text.
- Dark plum `#403135` — section structure.
- Oxblood `#C13E50` — active project signal and the cinematic opening.
- The optional light theme uses warm paper `#FAF7F6`, charcoal `#21191C`, and the same oxblood signal.

## Type

Syne for the bold opening and project identity, Manrope for body text, Cormorant Garamond only for the cinematic intro. The main page uses two families, giving it a different voice from Wande's serif card hero.


Everything aligns to one left edge except the current-role note and project facts. The content, not boxes or shadows, sets the hierarchy. Project previews retain their native aspect ratio so the full image stays visible.

## Audit before build

No rounded card grid, coloured keyword, decorative section numbering, icon tiles, fake metrics, or repeated entrance animations. The all-time Rivo values remain plainly attributed to the product. The four selectors reflect actual projects, and the live image changes with the selection. The default black and red palette carries the opening into the page.
